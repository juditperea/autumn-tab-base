# autumn-tab-base

Crea el esqueleto mobile-first con 5 tabs: Inicio/Feed, Buscar, Escanear, Clubs, Perfil.
Usa Tailwind + shadcn/ui, modo claro/oscuro y tema otoñal (naranjas suaves, verdes bosque, amarillos cálidos).
Añade placeholders de cada pantalla con rutas y navegación funcionando.
No implementes backend aún. Muestra un preview navegable.

Checklist al revisar: tabs visibles, navegación fluida, estilos coherentes claro/oscuro.
